# TinyTag

## Project Overview
Our project falls under the interactive game theme. Tiny Tag is a 3D game built in Unity where players play tag inside a large room. The players are tiny compared to the environment, so
everyday objects such as furniture, plants, and toys appear huge and act as obstacles, ramps, and hiding spots. One player is "it" and tries to tag the others before the round timer ends. A tagged player becomes the new "it."

## Goals We'd Like To Meet
1. Build a 3D room environment scaled so the players are about the size of a toy figure.
2. Implement player movement: walking, running, jumping, and climbing onto objects.
3. Implement a third-person camera that follows the player and avoids clipping through
objects.
4. Implement the tag logic: tag detection through collision, passing the "it" role, a round timer, and a win condition.
5. Support at least two players using local split-screen.
6. Add lighting, shadows, textures, a simple menu, and an on-screen timer to deliver a complete playable game.
