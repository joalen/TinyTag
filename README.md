# TinyTag

## Project Overview
Our project falls under the interactive game theme. Tiny Tag is a 3D game built in Unity where players play tag inside a large room. The players are tiny compared to the environment, so everyday objects such as furniture, plants, and toys appear huge and act as obstacles, ramps, and hiding spots. One player is "it" and tries to tag the others before the round timer ends. A tagged player becomes the new "it."

In our version, a rubber duck and a rubber frog face off in local split-screen inside a giant bedroom, using the bed, desk, chair, dresser, toy box, and toy blocks as stepping stones and hiding spots.

## How to Play
- One player starts as **"it"** at random, marked by a spinning red diamond above their head.
- Touch the other player to tag them and pass "it" on. The tagged player is frozen briefly, and there's a short cooldown so you can't tag straight back.
- "It" moves slightly faster so they can catch up.
- Each round lasts **90 seconds**. Whoever is **not** "it" when time runs out wins.

## Controls
| | Duck (Player 1) | Frog (Player 2) |
|---|---|---|
| Move | W A S D | Arrow keys |
| Jump | Space | Right Ctrl (or Numpad 0) |
| Sprint | Left Shift | Right Shift |
| Turn camera | Q / E (or mouse) | , / . |

Gamepads also work: left stick to move, right stick for the camera, A to jump, LT to sprint.
In menus, press **Enter** to play or rematch and **Esc** to go back or quit.

## Features
- Bedroom scaled so the players are toy-sized, with lighting, shadows, and textured floor, rug, and walls
- Split-screen with a third-person camera for each player that doesn't clip through furniture
- Duck and frog characters with waddle/hop animations and a squeak on every jump
- Main menu, round timer, countdown, player status and stamina HUD, and a winner screen with rematch

## Running It
- **In Unity:** open `Assets/Scenes/Bedroom.unity` and press Play.
- **Windows build:** File → Build Profiles → Windows → Build.
- **Rebuilding the room:** the scene is generated by **TinyTag → Build Bedroom Scene** (`Assets/Editor/TinyTagSceneBuilder.cs`). Change the layout, character models, sizes, or speed there and re-run it. Re-running overwrites `Bedroom.unity`, so hand edits to the scene are lost.

## Project Structure

| `Assets/Scripts/Camera/` | Third-person follow camera |

| `Assets/Scripts/UI/` | Menu, HUD, and winner screen |
| `Assets/Editor/` | Scene builder |
| `Assets/Resources/TinyTagControls.inputactions` | Key bindings for both players |
| `Assets/Generated/` | Materials and textures created by the scene builder |
